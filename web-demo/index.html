HMVC

Browser-based voice conversion · experimental

Choose a source recording and, optionally, a target voice recording. Conversion runs locally in this browser using HMVC's Python DSP pipeline.

First launch downloads Pyodide, NumPy, and HMVC's Python source. It may take a while and use substantial memory. Try short clips first.

Audio is not uploaded to a conversion server. The browser decodes and resamples audio; HMVC's Python code performs the conversion. JavaScript here is only the browser/API bridge and interface.
